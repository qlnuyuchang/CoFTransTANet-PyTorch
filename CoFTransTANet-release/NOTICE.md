# Third-party components

This repository contains or adapts code associated with the following works:

1. **Res2Net: A New Multi-scale Backbone Architecture**. The Res2Net-50 model
   definition and pretrained-weight URL are retained in `lib/Res2Net_v1b.py`.
2. **The Fully Convolutional Transformer for Medical Image Segmentation**,
   WACV 2023. Transformer building blocks adapted for this project are in
   `lib/FCT.py`. The source project identifies its implementation as MIT
   licensed.
3. The metric evaluation script retains attribution to Lart Pang and uses the
   `py_sod_metrics` package.

The original authors retain copyright in their respective components.
